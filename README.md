# Birthday webpage

A simple static webpage starter. Open `index.html` in a browser to preview it.

## Structure

```text
01_Birthday/
├── index.html          Main page
├── css/style.css       Styles
├── js/script.js        Interactions
├── assets/
│   ├── images/         Photos and graphics
│   └── audio/          Music and sound
├── .gitignore
└── README.md
```

Use relative paths such as `assets/images/photo.jpg` in `index.html`. This keeps the page portable when it is uploaded to GitHub or published with GitHub Pages.

## Publishing

To publish with GitHub Pages, configure this repository to deploy from the `main` branch and the root folder in **Settings → Pages**.
